# CertSim Public CI Mirror

This repository is a disposable public CI mirror used only for CertSim validation.

It is not the CertSim source-of-truth repository. It contains no production credentials or protected exam question banks, and it cannot deploy CertSim production.

Candidate snapshots correspond to private source SHAs recorded in `CI_SOURCE_SHA.txt`. Do not add proprietary CertSim content, operational secrets, or production deployment capability here.
